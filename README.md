## Built with

- Astro + Starwind UI
- Tailwind CSS

## Setup the project

Clone the repository

```bash
git clone https://github.com/whoiseno/whoiseno.git
```

```bash
cd whoiseno
```

Install dependencies

```bash
pnpm install
```

Run the development server

```bash
pnpm dev
```
