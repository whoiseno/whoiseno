Starting a blog is not easy, whether you are technical or not. You have to think about what to write about, who your target audience is, and what is your publishing strategy. As a developer, I was faced with the thought of should I build my blog from scratch or use a headless provider.

In this post, I am going to guide you through on how to create a simple blog from scratch using **Astro**, **Tailwind CSS**, **MDX**, and **Keystatic**. The project will be deployed on **Netlify**.

## Project Scaffolding

Let's start by creating our project. Open terminal and enter the following prompt.

```bash
pnpm dlx create astro@latest
```

<Callout variant="note" defaultOpen>
  This command scaffolds a new project using `pnpm` as your package manager.
</Callout>
