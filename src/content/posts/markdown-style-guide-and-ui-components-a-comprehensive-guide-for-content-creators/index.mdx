**Markdown** has become the universal language for formatting text on the web, powering everything from GitHub repositories to content management systems. Its simplicity and readability make it the go-to choice for developers, writers, and content creators who want to focus on writing without getting bogged down in complex formatting tools.

Meanwhile, **UI components** serve as the visual and interactive elements that bring digital experiences to life. From callouts that highlight critical information to cards that organize content into digestible chunks, these components create intuitive, engaging interfaces that guide users through information and actions seamlessly.

Whether you're a developer documenting code, a technical writer creating tutorials, a designer building user interfaces, or a content creator looking to enhance your digital presence, this guide will equip you with the knowledge to leverage both Markdown's formatting power and UI components' visual impact

Let's dive into the essential syntax and components that will elevate your content creation game.

## Markdown

### Headers

Headers create hierarchical document structure and improve readability. Use 1-6 `#` symbols for different heading levels, with one `#` being the largest. Headers help organize content into sections and are crucial for SEO and accessibility. Always add a space after the `#` symbol.

# Header 1 (Largest)

## Header 2

### Header 3

#### Header 4

##### Header 5

###### Header 6 (Smallest)

### Bold

Bold text emphasizes important words or phrases, making them stand out visually. It's commonly used for key terms, warnings, or critical information. <Mark>Use double asterisks or double underscores before and after text</Mark>. Both methods produce identical results, so choose based on preference or consistency with your team's style guide.

**bold text with asterisks**

### Bold + Italic

Combine bold and italic for maximum emphasis on exceptionally important text. <Mark>Use triple asterisks or underscores, or mix both formatting styles</Mark>. This is rarely used but effective for critical warnings or highlighting key concepts that need both strong emphasis and distinction from surrounding text.

***bold and italic***

### Italic

Italic text provides subtle emphasis, often used for titles, foreign words, technical terms, or gentle emphasis. It's less visually prominent than bold but still draws attention. Use single asterisks or single underscores. Italics are commonly used in academic writing, book titles, and to convey tone or stress in written communication.

*italic text with asterisks*

### Strikethrough

Strikethrough indicates deleted, outdated, or incorrect content. It's part of GitHub Flavored Markdown (GFM) and useful for showing edits, completed tasks, or deprecated information. Use double tildes before and after text. Commonly seen in collaborative documents, changelogs, and tracking modifications without completely removing original content.

~~This text is deleted~~

### Links

Links connect to other web pages, documents, or sections within the same page. Format is `[link text](URL)`. The text in brackets becomes clickable, and the URL in parentheses is the destination. You can also add optional titles that appear on hover by adding text in quotes after the URL.

### Unordered Lists

Unordered lists display items without numerical order, ideal for collections where sequence doesn't matter. Use `-`, `*`, or `+` followed by a space. Lists improve readability and help break down complex information into digestible chunks. You can nest lists by indenting 2-4 spaces.

* First item
* Second item
* Third item

### Ordered Lists

Ordered lists show items in sequential or ranked order. Use numbers followed by periods. Markdown automatically numbers items sequentially, so you can use `1.` for all items and it will render correctly. Useful for step-by-step instructions, rankings, procedures, or any content where order matters.

1. First item
2. Second item
3. Third item

### Nested List

These type of lists can be unordered or ordered.

* Main item
  * Sub item
  * Another sub item
* Another main item

### Blockquotes

Blockquotes highlight quotations, important notes, or content from other sources. Use `>` at the start of lines. You can nest blockquotes with multiple `>` symbols and combine them with other Markdown syntax. They're commonly used for citations, testimonials, callouts, or distinguishing referenced material from original content.

### Horizontal Rule

Horizontal rules create visual separators between content sections. Use three or more hyphens, asterisks, or underscores on their own line. They render as a horizontal line across the page. Useful for breaking up long documents, separating distinct topics, or creating visual breathing room in dense content.

### Tables

Tables organize data in rows and columns for easy comparison and readability. Use pipes `|` to separate columns and hyphens `-` for the header row. Tables are essential for presenting structured data, comparisons, or specifications.

| Header 1 | Header 2 | Header 3 | Header 4 |
| -------- | -------- | -------- | -------- |
| Cell 1   | Cell 2   | Cell 3   | Cell 4   |
| Cell 5   | Cell 6   | Cell 7   | Cell 8   |
| Cell 9   | Cell 10  | Cell 11  | Cell 12  |

### Inline Code

Inline code displays short code snippets, commands, or technical terms within regular text using monospace font. Wrap text with single backticks. It's perfect for variable names, function calls, file paths, or any technical terminology that should stand out from prose. Commonly used in technical documentation and tutorials.

Example

* Use the `print()` function in Python.
* Navigate to `/home/user/documents` directory.
* Set the `background-color` property to `#fff`.

### Code Blocks

Code blocks display multiple lines of code with syntax highlighting and preserve formatting. Use triple backticks (\`\`\`) before and after code, optionally specifying the programming language for syntax highlighting. Indenting four spaces also creates code blocks but without language specification. Essential for tutorials, documentation, and technical writing.

* Below is an example of a code block.

```ts
// File name: example.ts
const fullName = "Enoabasi Essien";

function displayGreeting(name: string) {
  return `Hello! ${name}`;
}

console.log(displayGreeting(fullName));
```

#### Syntax Highlighting

Syntax highlighting colorizes code based on programming language rules, improving readability. Specify the language after opening triple backticks. Many processors support 100+ languages including JavaScript, Python, HTML, CSS, SQL, etc. Proper highlighting helps readers understand code structure and identify elements quickly.

### Images

Images display visual content inline. Format is `![alt text](image URL)`. The alt text describes the image for accessibility and appears if the image fails to load. You can also add optional titles in quotes. For better control, you can use HTML `<img>` tags with width/height attributes in most Markdown processors.

## UI Components

### Callouts

Callouts are prominent boxes that draw attention to important information, tips, warnings, or notes within content. They typically use distinct background colors, borders, and icons to indicate their purpose (info, warning, error, success). Callouts break up text monotony and ensure critical information doesn't get overlooked. Common types include informational (blue), warning (yellow/orange), error (red), and success (green). They're widely used in documentation, tutorials, and educational content to highlight key points, best practices, or potential pitfalls.

</Callout>

</Callout>

### Highlight

Highlights emphasize specific text portions by applying visual treatments like background colors, borders, or text styling. They draw readers' eyes to key terms, definitions, code snippets, search results, or important phrases within larger text blocks. Highlights can be subtle (light background) or bold (bright colors) depending on emphasis needs. Common uses include marking search query matches, indicating new or updated content, showing active selections, or differentiating technical terms from regular text in documentation and educational materials.

### Steps

Steps components guide users through sequential processes by breaking complex tasks into ordered, manageable stages. They visually indicate progress, show current position, and display completed versus remaining steps. Common in onboarding flows, checkout processes, form wizards, and tutorials. Steps typically include numbered indicators, connecting lines, step titles, and optional descriptions. They may allow backward navigation to previous steps or lock future steps until current ones complete. This pattern reduces cognitive load and increases task completion rates.
